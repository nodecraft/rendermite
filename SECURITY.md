# Security policy

Please do not report security vulnerabilities through public issues, discussions or pull requests.

Report them privately using GitHub's [Report a vulnerability](https://github.com/nodecraft/rendermite/security/advisories/new) form on this repository. Include what you found, how to reproduce it, and the version affected. We will acknowledge the report and keep you updated as we work on a fix.

Only the latest published version of `@nodecraft/rendermite` receives security fixes.
